## RVfpgaEL2 SoC - Basys3 Sub-Repository

This is a sub-repository of the **RVfpgaEL2 SoC** adapted for the **Basys3** FPGA board.  
It includes all source files, **build scripts**, programming/debug configuration files, and simulation/testbench sources.  
The repository provides users with a clean and simple project structure for developing the **RVfpgaEL2 SoC** on the **Basys3 FPGA** platform.  

The main repository can be found [here](https://github.com/Kitsudora/RVFPGA-3-0-Local-Copy).
